# Internal JML adjustment fixtures

Generated by `inst/validation/jml-general-inputs-20260928.R`; evidence and scope
are recorded in `inst/validation/jml-general-inputs-20260928.md`. These fixtures
test internal equations and covariance, not a public corrected-JML fitter.

- `jml-adjustment-reference.rds`: exact frozen response-count calculations from
  `jml-design-adjustment-20260927.R`, which reuses the earlier profile-bias
  reference. Two shared owners, two structural vectors, sparse exposure
  (2, 1, 0, 2), three categories, orders 0/1/2/4. Stores observed long data,
  coordinates, scores and raw profile criteria for regression comparisons.
- `jml-adjustment-general.rds`: independently generated three-judge,
  two-criterion, four-category observed data, with seed 9283101. There are
  400 Persons and two fixed sparse rosters of 200 Persons, with six ratings
  each. Stores explicit-order 2/4 roots and matching full-Jacobian Person
  covariance from two-start development fitting. It is a numerical regression
  fixture; a single sample does not establish bias, coverage or order choice.

The test file separately enumerates a literal 64-response problem for two- and
three-level slope owners, verifies coordinate relabeling, covariance influence
and roster decomposition, and compares existing native GPCM probabilities.
Those independent checks prevent fixture self-consistency from being treated
as the only evidence. The original equation/covariance tests need no root
solver. Added runtime tests use optional `nleqslv` to reproduce saved roots
from deterministic starts, test point/covariance separation and failure handling,
and compare parameter tables and transformed covariance with native expansion.
They reuse these data; they do not regenerate a sampling study.
